## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding |
| sm | 8px | Avatar-to-text gap, form field gap |
| md | 16px | Card internal padding, form row spacing |
| lg | 24px | Section padding, avatar margin below |
| xl | 32px | Profile header vertical padding |
| 2xl | 48px | Major section breaks between profile sections |
| 3xl | 64px | Page top/bottom padding |

Exceptions: Avatar touch target minimum 44px (non-interactive display size: 80px on desktop, 64px on mobile). File input trigger button minimum height 44px.

Source: Codebase pattern (p-4, gap-2, gap-4, mt-3, mt-4, px-5, py-12 observed in existing components). Exceptions are WCAG 2.5.5 touch target standard.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (text-base) | 400 (regular) | 1.6 |
| Label | 14px (text-sm) | 400 (regular) | 1.5 |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

Notes:
- Body line-height 1.6 matches `globals.css` override (not Tailwind's 1.5 default).
- Credential badge text uses Label size (14px) at weight 600 — exception for small high-emphasis labels.
- Username on public profile page uses Display size (28px, semibold).
- Post history item title uses Body size (16px, semibold) with regular body text below.

Source: Observed font-semibold text-base, text-sm, text-xs in thread-card.tsx and post-item.tsx. globals.css sets line-height: 1.6.

|------|-------|-------|
| Dominant (60%) | #ffffff / oklch(1 0 0) | Page background, card backgrounds, form surfaces |
| Secondary (30%) | oklch(0.97 0 0) (--muted) | Profile header background, settings sidebar, post history row hover |

Secondary color `#00a86b` (--secondary, emerald green) is NOT used in Phase 5 — reserved for article-category labels established in Phase 3. Do not apply it to any profile UI.

Source: `globals.css` CSS custom properties. Accent-use list derived from Phase 5 UI surfaces (PROF-01, PROF-02, PROF-03).

## Page Inventory

### `/profile/[username]` — Public Profile Page

Layout: single-column, max-width 800px, centered. No sidebar.

Sections (top to bottom):
1. **Profile header** — avatar (80px), username (Display 28px semibold), join date (Label muted), credential badge.
2. **Bio block** — short bio text (Body 16px), shown only if set. If empty and own profile: "Add a bio in your settings" link. If empty and other user: section hidden.
3. **Post History** — heading "Discussions" (Heading 20px semibold), paginated list of threads and posts authored by the user. Each row shows: thread title (Body 16px semibold), excerpt (Label muted, line-clamp-2), relative timestamp (Label muted), link to `/forum/[categorySlug]/[threadSlug]`. Pagination: 20 items per page using existing `PaginationControls` component.

### `/settings/profile` — Profile Settings Page

Layout: single-column, max-width 640px, centered. No sidebar.

Sections:
1. **Avatar** — current avatar display (80px), "Upload new photo" button (Button primary), "Remove photo" button (Button destructive, only shown if avatar exists). File constraints: JPEG/PNG/WebP, max 2MB. Upload stores to Supabase Storage bucket `avatars`.
2. **Credential Badge** — Select dropdown with options: RN, NP, MD, DO, PharmD, PA, CMIO, CIO, Health IT, Other. Label above: "Your professional credential" (Label 14px). Helper text below: "Displayed next to your name on forum posts." (Label muted 14px).
3. **Bio** — Textarea, max 280 characters. Label: "About you". Character count shown below (e.g. "143 / 280"), counter turns accent color at 250+.
4. **Save** — "Save Settings" Button (primary variant, full-width on mobile, fixed-width 160px on desktop), anchored to bottom of form.

## Interaction States

### Avatar Upload

| State | Visual |
|-------|--------|
| Default | Avatar shown; "Upload new photo" button below |
| Uploading | Button text becomes "Uploading…"; button disabled; spinner icon (Loader2 from lucide, 16px, animate-spin) |
| Success | New avatar replaces old immediately via optimistic URL; toast notification "Avatar updated" |
| Error (size) | Inline error below input: "Photo must be under 2MB." Destructive color text, no toast. |
| Error (type) | Inline error: "Only JPEG, PNG, or WebP files are accepted." |

### Credential Badge on Forum Posts

After Phase 5, `PostItem` and `ThreadCard` must display the credential badge next to the username. Badge renders as: `<Badge variant="outline">RN</Badge>` in accent border color (#0066cc). Size: text-xs (12px), semibold. Displayed only when credential is set; hidden when null.

### Settings Form Save

| State | Visual |
|-------|--------|
| Idle | "Save Settings" button enabled |
| Submitting | Button disabled; text "Saving…"; no spinner (button width preserved) |
| Success | Button returns to "Save Settings"; toast "Profile updated" (bottom-right, 3s auto-dismiss) |
| Error | Toast "Failed to save. Try again." Destructive color. Form state preserved. |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (settings) | "Save Settings" |
| Secondary CTA (avatar) | "Upload new photo" |
| Empty state — no bio (own profile) | Heading: "No bio yet" / Body: "Tell the community about your clinical background." / Link: "Add one in settings" |
| Empty state — no bio (other user) | Section hidden entirely |
| Empty state — post history | Heading: "No posts yet" / Body: "This member hasn't posted in the forum yet." |
| Empty state — post history (own profile) | Heading: "You haven't posted yet" / Body: "Join a discussion or start a new thread." / Link: "Go to Forum" |
| Error — avatar upload size | "Photo must be under 2MB." |
| Error — avatar upload type | "Only JPEG, PNG, or WebP files are accepted." |
| Error — save settings | "Failed to save. Try again." |
| Destructive confirmation — remove avatar | No modal confirmation. Button label: "Remove photo". On click: immediate removal with toast "Avatar removed". Reversible by uploading a new photo. |
| Credential badge helper | "Displayed next to your name on forum posts." |
| Character count (bio) | "{n} / 280" — turns accent (#0066cc) at 250, destructive at 281+ (prevent submit) |

## Accessibility

- Avatar `<img>` alt text: "{username}'s profile photo" when set; "" (empty) when decorative fallback initials shown.
- Credential Select: `<label>` with `htmlFor` wired to Select trigger `id`.
- File input: visually hidden `<input type="file">` triggered by button; button has `aria-label="Upload profile photo"`.
- Form errors: `role="alert"` on inline error messages; `aria-describedby` on the input that caused the error.
- All interactive elements minimum 44px height (enforced via `min-h-[44px]` on buttons).
