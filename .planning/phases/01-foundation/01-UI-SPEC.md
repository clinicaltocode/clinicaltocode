# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (to be initialized during Phase 1 execution) |
| Preset | none — manual token configuration via Tailwind v4 CSS-first `@theme` |
| Component library | radix (via shadcn primitives; `components/ui/` only — skeleton scope) |
| Icon library | lucide-react (shadcn default) |
| Font | System stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif` |

**Note (CONTEXT.md):** shadcn is initialized as part of Phase 1 scaffolding. No preset string is used — brand tokens are encoded directly in `globals.css` under the `@theme` directive per RESEARCH.md. `components/ui/` holds shadcn primitives; domain components go in `components/`.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card padding inner |
| lg | 24px | Section padding, sidebar widget padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Nav height: 70px (from `index.html` nav — carries forward as-is; not a spacing token, a fixed layout dimension)
- Touch targets: 44px minimum height for all interactive elements (accessibility floor; applies to buttons and nav links)
- Content max-width: 1200px (layout constraint, not a spacing token)

---

## Typography

Source: `index.html` CSS and CONTEXT.md decision to carry forward the system font stack.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.6 |
| Label | 14px | 400 (regular) | 1.5 |
| Heading | 22px | 600 (semibold) | 1.4 |
| Display | 48px | 600 (semibold) | 1.2 |

**Notes:**
- Body line-height 1.6 matches `index.html` `body { line-height: 1.6 }`
- 14px label is used for article meta, footer copy, stat descriptions, and form helper text
- 22px heading covers article card titles and sidebar widget headings
- 48px display is the hero `h1` — scales to 32px at mobile breakpoint (≤768px) per `index.html` responsive rules; 600 semibold is sufficient on the hero gradient background
- Section headings (`h2` on article index) are 32px at semibold — treated as a heading variant, not a separate type role
- Font weights used: 400 regular, 600 semibold (2 weights only)

## Color

Source: `index.html` `:root` CSS variables and CONTEXT.md locked decisions.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (white) + `#f8f9fa` (bg-light) | Page background (`#fff`), stats bar, sidebar widget backgrounds (`#f8f9fa`) |
| Secondary (30%) | `#1a1a1a` (text-primary) + `#e5e7eb` (border) | Body text, nav footer background, borders, dividers |
| Accent (10%) | `#0066cc` (primary) | See reserved-for list below |
| Accent dark | `#0052a3` (primary-dark) | Hover state for accent elements |
| Secondary accent | `#00a86b` (secondary) | Success states, credential badges (future phases), positive indicators |
| Hero gradient | `#667eea → #764ba2` | Hero section, newsletter widget, article image placeholders |
| Destructive | `#dc2626` (red-600, Tailwind default) | Destructive actions only (no destructive actions in Phase 1) |
| Text secondary | `#666666` | Meta text, subtitles, captions |

**Accent (`#0066cc`) reserved for:**
- Logo / brand wordmark
- Nav link hover state
- Primary CTA button background (when on white surface)
- Article category labels
- "Read more" link text
- Stat item numbers in the stats bar
- Focus ring on interactive elements (accessibility)

**Hero gradient (`#667eea → #764ba2`) reserved for:**
- Hero section background
- Newsletter sidebar widget background
- Article card image placeholder backgrounds

**Tailwind v4 `@theme` token names (from RESEARCH.md):**
```
--color-primary: #0066cc
--color-primary-dark: #0052a3
--color-secondary: #00a86b
--color-secondary-dark: #008055
--color-hero-from: #667eea
--color-hero-to: #764ba2
```

## Layout Contract (Skeleton Homepage)

**Primary focal point:** hero h1 display text.

The skeleton homepage must match the visual structure of `index.html` sufficiently to confirm the stack is working. Not a pixel-perfect rebuild — just structural validation.

| Zone | Implementation |
|------|----------------|
| Nav | Sticky, white background, 70px height, `border-b`, logo left + nav links right |
| Hero | Full-width, `bg-gradient-to-br from-hero-from to-hero-to`, `py-[80px]`, centered text + 2 CTAs |
| Content area | `max-w-[1200px] mx-auto px-5`, two-column grid (`1fr 300px`), `gap-10` |
| Footer | Dark background (`bg-[#1a1a1a]`), white text, `pt-[60px] pb-[30px] mt-[80px]` |
